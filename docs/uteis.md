
Caso deseje contribuir ou levantar uma issue, utilize a área de [Issues do GitHub](https://github.com/nk-northkeep/nk-land-one/issues).

## GitHub Pages
- Workflow: `.github/workflows/pages.yml` (push em `main` ou execução manual)
- Origem no GitHub: **Settings → Pages → GitHub Actions**
- Domínio: `conheca.one.northkeep.com.br` (arquivo `CNAME`)
- DNS Cloudflare: CNAME `conheca.one` → `nk-northkeep.github.io` (DNS only)
