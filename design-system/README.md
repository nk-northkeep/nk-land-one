# Design System Usage

## Estrutura
- `tokens.css`: variáveis globais de cor, espaçamento, tipografia, radius e sombras.
- `design-system.md`: referência de identidade visual e regras de uso.
- `components/*.html`: exemplos base de componentes para reaproveitamento.

## Como usar
1. Carregue `design-system/tokens.css` antes do `style.css`.
2. Reutilize as classes `ds-*` existentes na landing para manter consistência.
3. Ao criar novas seções, monte-as combinando `ds-card`, `ds-button`, `ds-badge` e `ds-alert`.

## Direção recomendada
- Preserve alto contraste.
- Evite gradientes excessivos fora do hero e dos CTAs.
- Prefira uma única ação primária por seção.
- Identidade ONE / NorthKeep; não misturar outros produtos nesta land.
